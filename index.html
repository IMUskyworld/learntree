learntree 需要用一个本地 HTTP 服务打开

你现在是双击 index.html 打开的（file://）。 浏览器不允许在 file:// 页面里加载 ES Module，所以界面无法启动。 这不是数据出错，换一种打开方式就好。

在项目目录下执行下面任意一条，然后访问 http://127.0.0.1:8080/：

python -m http.server 8080
# 或
npx serve .

数据存在这个浏览器的 localStorage 里；换打开方式不会丢，但换浏览器需要先用「导出 / 导入」。
